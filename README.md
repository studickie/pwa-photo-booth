# photo-booth

A web-based media capture app that leverages browser API's for WebRTC, IndexedDB and Service Workers, to create an offline-capable app for capturing, storing and managing your photos.

## Installation

**A mobile device is recommended for best experience.**

1. Using Chrome or Safari, [**install the PWA**](https://studickie.github.io/pwa-photo-booth/index.html).

2. When prompted, grant the browser permission to access the device's microphone and camera.
